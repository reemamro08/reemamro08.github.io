Connecting Bears

An interactive Berkeley personality quiz with 6 scenarios, 16 branching follow-ups, and 5 result types. Navigation and scoring run from a single answer-history stack, so Back reverts both the screen and the score.

Built as a single HTML file with no JavaScript libraries, using hand-built SVG art, canvas confetti, Web Audio sound effects, and a shareable result card.

Digital Combination Lock

A keypad-activated door lock built on an Arduino Uno with a 4x4 keypad, I2C LCD, piezo buzzer, and servo motor.

Passcode entry is masked on the LCD, the buzzer signals right or wrong codes, and one code locks and unlocks the servo between two positions.
